## Rung model (gx3gen / gx3comp)
`(branches, series, outputs)`:
- `branches`: OR group at the left, list of rows; each row a list of contacts (`'X0'`, `'/X1'` = NC). Multi-contact OR rows are drawn but **not compilable** by gx3comp (needs ORB, unobserved).
- `series`: contacts after the OR group on row 0.
- `outputs`: `'Y0'` coil, `'SET M20'`, `'RST C0'`, `'PLS M10'`, `'OUT T0 K50'`, `'MOV C0 D1'`, `'INC D10'`, `'ZRST M30 M32'`. Several outputs = parallel outputs. OR group + several outputs in one rung not supported.
- Devices supported: X, Y (octal), M, SM, T, C, D. Numbers 0–127 and 256–32767 (128–255 encoding unobserved → error).

## .gx3 format (decoded, verified)
- ZIP; entry names use backslashes — rebuild with `zi.filename = i.orig_filename`.
- Ladder source: `*_LDDB.db` (SQLite) table `LadderBlocks(id '_guid/<uuid>', pos REAL, blocktype 0|5(END), data, rowsize, translated, ConvTarget)`.
- Data: `V1:<n>:<len of each token>:<tokens>:cb{fg=fg{dim=WxR:es=[...]:vs=[v{pos=x,y}...]}}`. Tokens in element order (row-major). Contact `a:X` / NC `b:X` (element keeps `ct=a`), coil `c:Y`, `SET:M`, `RST:C`, `PLS:M` (`ct=p`), `INC:D` (`A16s`), `MOV:C:D` (`A16`), `ZRST:M:M` (`Aea`), timer/counter `OUT__16:T:K_1` with `c{s=#:v=50:si=s}`. Wire `e{s=-:pos=x,y}`. `v{pos=x,y}` = vertical line at left edge of column x between rows y-1 and y.
- One unparseable block blanks the whole ladder in GX (no error dialog).
- Writing only LDDB with `translated=0` is accepted; GX Rebuild All regenerates the rest.
- Compiled artefacts: `*_MilDB.db` (MIL text: contacts `A/B` with `lt=l/a/o`, coil/PLS/OUT T → `OUT`, ZRST → `RST`), `*_StepInfo.db` (T_Block/T_Step; steps: contact 2, OUT/SET/RST bit 2, RST T/C 3, PLS 3, INC 3, ZRST 4, OUT T/C K 5, MOV 5, END 1), `ConvertData\...\PouPCode.pcode` (00 + records `[u32 len][0x11][guid bytes_le][code]`), `ProgramFilePCode.pcode` (concatenated code), `Program.qpg`.
- Machine code: instruction `07 grp steps op 00 ff 07` + operands `len a0 devcode num_le len` (len = body+2); constant `a0 a1 value`. Devcodes M 01, SM 02, X 10, Y 11, D 20, T 42, C 46. Ops: LD/LDI/AND/ANI/OR = `00 02 00..04`; OUT `02 02 00`; SET `02 02 03`; RST `02 02 04` (T/C `02 03 04`); PLS `02 03 05`; OUT T/C K `02 05 01`; INC `22 03 00`; MOV `24 05 00`; ZRST `2b 04 19`; END `02 01 15` (+`07`). gx3comp matches GX byte for byte (880-byte ProgramFilePCode).
- `Program.qpg`: header (u32@8 = code-section offset, u32@12 = file size), index table @0x204, two LZMA_ALONE blobs (labels; bundle of .body/.step/.Xml/PouPCode copies), constant `ca70ae19d7a543cb`, ProgPou name, device table, code section `[V 8B][00 00 d0 2f 00 00 00 00][V 8B][u32 total steps][code]`.
- **V is a per-build ID, not a checksum**: same program built twice by GX → identical code, different V and bundle. Self-compiled file with stale V/bundle opens in GX as converted. Real-PLC acceptance untested.

## GUI driving (PowerShell, no windows-mcp)
- Foreground: tap Alt (`keybd_event 0x12`) then `SetForegroundWindow`; verify with `GetForegroundWindow`.
- Rebuild All = Shift+Alt+F4 (`SendKeys '+%{F4}'`). Dialogs are `#32770`; find with UIAutomation **Descendants** search; buttons are Panes without Invoke → click centre of `BoundingRectangle` with `mouse_event`.
- Save: answer **Yes** on the close prompt (Ctrl+S was unreliable). Match `*(Y)*`; keep `.ps1` ASCII-only (PS 5.1 reads UTF-8 w/o BOM as ANSI).
- Typing in the ladder editor: select a cell, send mnemonic + `{ENTER}` in ONE SendKeys call (`LD M0{ENTER}`). Works for series rungs; OR branches and multiple outputs come out wrong. `{HOME}` goes to the step column (error). Use full-screen CopyFromScreen for screenshots (MainWindowHandle can point at popups).
- To learn a new instruction's encoding: type a sample rung in GX, save, dump LDDB (and compiled files after Rebuild All).
